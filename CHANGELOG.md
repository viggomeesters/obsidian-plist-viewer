# Changelog

## 0.1.1 - 2026-10-25

- Cross-platform production build.
- Current Community installation documentation.


All notable changes to PLIST Viewer are documented here.

## 0.1.0 - 2026-06-08

- Initial public release.
- Add read-only `.plist` and `.mobileconfig` file views.
- Add XML plist parser for dict, array, string, integer, real, bool, date, and data values.
- Add binary plist detection with unsupported fallback.
- Add tree view with search, key paths, type badges, masked secret-like values, and outline.
- Add source view with line numbers and lightweight XML highlighting.
- Add configuration profile summary and payload list.
- Add warnings for MDM, Wi-Fi credentials, VPN, certificates, root certificates, restrictions, unknown payload types, sensitive values, and removal-disallowed profiles.
- Add fixtures and parser/smoke/security tests.
